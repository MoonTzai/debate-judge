# AI Usage Disclosure Log

This file defines the disclosure practice for the future public project and JOSS paper. It is not a claim that every historical AI-assisted action has already been exhaustively reconstructed.

## Required record fields

For AI-assisted research, code, documentation, review, translation, or testing, record when materially relevant:

- tool/model or service identity when known;
- date or version window;
- task performed;
- human review performed;
- whether generated text/code was accepted, modified, or rejected;
- whether any private or third-party data was sent to an external service;
- links to the affected commit or research artifact once public.

## Authorship and responsibility

AI systems are not authors. Human maintainers/authors remain responsible for code, claims, citations, rights, privacy, and scientific interpretation. AI-generated review or red-team output is internal assistance unless an actual external peer-review process says otherwise.

## JOSS preparation

The submission-stage `paper.md` should include the then-current AI-use disclosure required by JOSS and should distinguish ordinary editing assistance from substantive research/code generation. Historical uncertainty should be disclosed rather than replaced by invented precision.
