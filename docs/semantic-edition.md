# Semantic Edition: 2026-09-24 r6 snapshot

## Provenance and scope

This snapshot packages the complete GPT6 r6 plain-language-enhanced candidate selected by the maintainer. It descends from existing public main history; judging implementation comes from r6. It is a separate branch, not a V10/Deliberative merge. Private r5 and r6 sources were not overwritten.

The SC integration, source-roster module, execution host, validators, settings, renderers, paragraph-aware plain-language implementation, reader guide and ten core units are retained. Differences are limited to authorized MIT metadata, a portable project-directory placeholder, LF source representation, browser branding, programmatic CSS backgrounds replacing excluded artwork, deterministic build metadata, public test/documentation entry points and file selection. No debate-specific rule or winner adjustment was added.

The [source inventory](source-inventory.json) records file origins. Complete files are included, not references to inaccessible originals. Private preparation keeps original complete files and a full comparison; those records are unnecessary to build the public repository.

## Included and excluded

Included: current rules/runtime closure, required compatibility imports, schemas/report assets, browser sources/HTML, synthetic/source-integrity tests, license, citation metadata and practical documentation.

Excluded: real debate transcripts, actual model reports/flight/session exports, private audits, API configuration, historical vendor snapshots, non-cleared artwork, redundant delivery HTML, tests requiring private evidence. The stale nested Claude controller is not a current runtime dependency and is excluded; root controller and complete Skill mirrors are included.

Historical cutover helpers remain dependencies of the original builder. Their external state/corpora are excluded; public browser production attestation remains `mode: off`. Normal Semantic Edition operation uses r6 SC integration.

## Verified scope

- The 35-block installer closure verifies against actual sources.
- Browser rebuild is reproducible; runtime loads offline; Node/Web rounds, prompts and SC policy match.
- Fifteen current deterministic test files pass, including a publication packaging test.
- Source-only/public fixture selection and secret scanning occur before push.
- No live model rerun or new judging/readability benchmark is claimed.

## Known inherited failures

Reproduced in both the unmodified r6 source and this public copy; the default runner reports them.

1. `tests/self-check.test.js`: three negative terminology cases mutate old strings no longer defining active semantics; an embedding-layout assertion expects no asset blocks after the controller, unlike the candidate's arrangement.
2. `pipeline-controller.js self-check`: also reports disagreement in its legacy embedded-block integrity check and R6a inline CSS comparison. The current installer verifier passes; the old check is still a FAIL.
3. `tests/key-engine.test.js`: four failures concerning legacy patchKeys representation, a fixed consumer-map count, strict key inventory, and the old compression key. Dictionary/consumer drift remains a limitation, not proof of complete interface correctness.

This is a research baseline with disclosed debt. Publication does not repair those mechanisms or make an all-green claim. Future work should test actual interfaces and semantic effects without restoring obsolete SC rules just to satisfy string assertions.

## Research boundaries

SC occurrence, completion, scope, persistence and adjudicative importance are separate judgments. In this branch, completion relevant to the principal dispute promotes the whole-debate mainline type; marginal completion remains local. This is a modeling choice, not a measured advantage.

Software checks establish only their stated properties. No new human-equivalence result, benchmark win, external adoption, archival DOI or accepted paper is claimed. Future evaluations should cover paraphrase stability, evidence-sensitive revision, repeated-reason inflation, partial contributions, model bias, failures and reader understanding.
