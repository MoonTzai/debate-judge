# Contributing

This repository candidate is being prepared for an open research-software release. Contributions should improve maintainability, documentation, tests, reproducibility, or research usability without weakening semantic correctness.

## Before contributing

- Use only material you have the right to contribute.
- Do not include match transcripts, course media, private reports, credentials, local paths, or internal audit/evidence files.
- Keep behavior-changing changes separate from documentation-only changes.
- Explain the research or maintenance need, the affected files, and the verification performed.
- Do not manufacture benchmark results, adoption claims, issue history, or pull-request history.

## Verification

A release-quality contribution should preserve the three Markdown distribution mirrors, the `install-skill.js::BLOCKS` closure, and generated-Web/source relationships. Run the project tests applicable to the changed area and report failures or skipped tests exactly. Passing software tests is not evidence that an adjudication is scientifically correct.

## Rights and licensing

The final public license has not yet been applied to this local candidate because the mixed code/rule/asset rights map is still being closed. Do not assume that material merely visible in the private development workspace is redistributable.

## Conduct and support

Technical disagreement should be resolved with reproducible evidence, precise source references, and respectful discussion. Security or privacy-sensitive reports should not paste secrets or personal data into public issues.
